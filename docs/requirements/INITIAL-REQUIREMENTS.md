# Initial System Requirements

## User

The primary user is an authorized clinic staff member.

## Functional Requirements

1. The system shall allow authorized staff to log in using a username and password.
2. The system shall allow staff to register a dental appointment.
3. Each appointment shall record an appointment number, patient name, address, contact number, dentist, treatment, date, and time.
4. The system shall allow staff to search for an appointment using its appointment number.
5. The system shall display all stored details of a selected appointment.
6. The system shall calculate the total bill using the treatment cost and consultation fee.
7. The system shall generate a bill or receipt.
8. The system shall provide useful clinic reports.
9. The system shall provide a help section for new staff.
10. The system shall allow the user to log out or safely exit.

## Important Technical Requirements

- Java-based implementation
- Distributed application with web services
- Database persistence
- Input validation
- Three-tier architecture
- Suitable design patterns
- Automated testing
- Git and GitHub version control

These requirements are an initial working summary and should be checked against the official CIS6003 assignment brief during development.

# Start Here

This ZIP is the initial folder for the CIS6003 Advanced Programming assignment.

## First actions

1. Extract the ZIP file.
2. Open the `Sunrise-Dental-Clinic-System` folder in IntelliJ IDEA or Visual Studio Code.
3. Create a public GitHub repository named `sunrise-dental-clinic-system`.
4. Initialize Git inside this folder.
5. Make the first commit before adding the full application.

## Suggested first Git commands

```bash
git init
git add .
git commit -m "Initial project setup and requirements"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the URL of your own GitHub repository.

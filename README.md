# Sunrise Dental Clinic Management System

## Module

CIS6003 Advanced Programming Assignment

## Project Overview

This project develops a computerized appointment and patient management system for Sunrise Dental Clinic in Colombo. The system will replace paper-based appointment records and help clinic staff manage appointments, patient information, billing, reports, and daily operations.

## Core Functions

- Staff login and logout
- Register dental appointments
- Search and display appointment details
- Update and cancel appointments
- Manage patients, dentists, and treatments
- Calculate treatment and consultation charges
- Generate bills and receipts
- Produce useful clinic reports
- Display a help section for staff

## Planned Technologies

- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA / Hibernate
- Thymeleaf
- Bootstrap
- MySQL
- Maven
- JUnit 5 and Mockito
- Git and GitHub
- GitHub Actions

## Planned Architecture

The project will use a three-tier structure:

1. Presentation layer — Thymeleaf pages and controllers
2. Business layer — service classes and business rules
3. Data-access layer — repositories, entities, and MySQL
